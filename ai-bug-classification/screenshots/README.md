# Screenshots

All visuals for this case study come from the **synthetic demo** in `../examples/`. No screenshots
of internal systems are used.

| File | Shows |
|---|---|
| `demo-run-1.txt` | First run: all six outcomes (auto-apply, retry, review, failure, human-protected skip) |
| `demo-run-2-rerun.txt` | Second run: every ticket skipped, zero model calls (idempotency) |
| `demo-audit-record.json` | Shape of the audit log entries |
| `demo-calibration.txt` | Calibrated vs flat confidence (the main lesson) |

Ready-made images used in the case study are in [`../images/`](../images/): the pipeline overview,
the decision outcomes and the calibration chart. They are SVGs that follow the reader's light or dark
theme, generated by `../images/make_images.py` from the same synthetic data.

To turn the terminal output above into images, run the commands in a terminal with a clean prompt and take a
screenshot, or render the Mermaid diagrams in `../architecture.md` with GitHub's built-in Mermaid
support.

## Not to be used

A screenshot of the real n8n canvas, Jira issues, the dashboard or the wiki page, even blurred or
cropped. Node names, field names, project keys, team names and taxonomy values are all visible
there, and redacting them does not make the material publishable.
